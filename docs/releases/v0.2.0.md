# v0.2.0 developer preview - draft release notes

Status: release preparation. This draft records the scope; it is not a claim that
release gates or clean-machine qualification have passed. Add final check results,

## Connected local companion

- Discover THEBEST-reviewed packs from the public GitHub workflow library and
  fetch them on demand. Verify the shipped curator key, exact artifact hashes,
  schema, expiry and consistency of review/evidence claims.
- Prepare a task through MCP and review its summary. Complete steps are available
  to inspect or edit, along with variables and authored workflow copies. Confirm
  the exact single-use plan explicitly. Original signed bytes are preserved;
  edited copies do not inherit a curator signature.
- Run `l1ght5p33d try` for the fixed synthetic poster fixture and review page.
  `serve` uses managed folders by default. New tools include
  `search_curated_workflows`, `prepare_task`, `get_task_status` and `get_cache_status`.
- Retain downloaded packs for 90 days without execution by default; configure
  1-3650 days with `--cache-retention-days`. Actual execution refreshes use.
  Active, pinned, modified and untracked content is protected; authored copies
  and receipts are outside eviction.

## Boundaries and migration

The immutable v0.1.0 assets do not include this guided companion. The first public
pack remains `poster-demo@0.1.0`; its signature records a Windows 11 synthetic
browser test with the older source runtime. It does not qualify every v0.2.0
environment. Authenticated live BandLab and native Windows input remain pending;
hosted Ubuntu CI is not native Linux desktop or WSL GUI qualification.

Human confirmation is the local review interaction and a rule for cooperating
agents. A returned review URL carries a capability, so an authorized client could
imitate its approval POST. There is no cryptographic proof of human presence or
isolation from unrestricted processes under the same OS account. Stale-plan,
cross-site and normal replay protections remain separate guarantees.

HTTP MCP and `try` provide browser review. Line-oriented `rpc` does not start HTTP;
it returns `review_url: null`, `review_mode: "local_terminal"` and local review
arguments for the exact plan. Use the same policy and state for terminal review.

THEBEST's website/P2P register is not deployed; the connected public source is
GitHub. Advanced configured native catalogs and Kubo import into the operator's
workflow library, outside the managed curated cache. No code or provider is
installed by downloading a pack. See the [companion guide](../companion.md).
