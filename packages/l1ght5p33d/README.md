# L1ght5p33d

Create, discover, adapt, combine and run local computer workflows using the
existing OpenAdapt Flow runtime. AI helps author and repair ordinary ASCII JSON
files; routine execution uses deterministic code. The library supports multiple
applications, with BandLab MIDI import as its first reference workflow. No AI
provider, cloud account, or screenshot egress is required.

The v0.2.0 Windows 11 developer preview connects on-demand THEBEST workflow packs,
signature verification and local review. Run `l1ght5p33d try` for the fixed
synthetic browser poster fixture: review the summary and explicitly approve when
ready. Complete steps and inputs are available to inspect or edit. `serve` starts
the local MCP companion with managed folders by default.

Downloads use a cache with 90 days of inactivity retention, configurable with
`--cache-retention-days` (1-3650). Actual execution refreshes use; authored copies
and receipts never expire through this cache. A curator signature describes its
exact test scope and does not authorize execution. Local confirmation relies on
the review interaction and cooperating clients, not cryptographic human presence.

The connected public GitHub library currently has one synthetic browser pack.
THEBEST's website/P2P register is not deployed. Live BandLab and native Windows
input qualification remain pending. See the repository README for the locked
installer, MCP session-token setup and current validation limits.

This is a history-preserving downstream fork of OpenAdaptAI/openadapt-flow.
Its MIT copyright and package boundaries are retained. L1ght5p33d is unofficial
and unaffiliated with OpenAdapt, BandLab, Suno, or other automated applications.
