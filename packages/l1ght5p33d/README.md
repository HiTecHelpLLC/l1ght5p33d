# L1ght5p33d

Create, discover, adapt, combine and run local computer workflows using the
existing OpenAdapt Flow runtime. AI helps author and repair ordinary ASCII JSON
files; routine execution uses deterministic code. The library supports multiple
applications, with BandLab MIDI import as its first reference workflow. No AI
provider, cloud account, or screenshot egress is required.

Windows 11 developer preview. See the repository README for the locked installer,
local fixture demos, MCP session-token setup, and current live-validation limits.

This is a history-preserving downstream fork of OpenAdaptAI/openadapt-flow.
Its MIT copyright and package boundaries are retained. L1ght5p33d is unofficial
and unaffiliated with OpenAdapt, BandLab, Suno, or other automated applications.
