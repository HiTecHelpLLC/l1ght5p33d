# CreateRelay

Local creation automation built as an extension of OpenAdapt Flow. Learned
workflows execute deterministically; AI helps author and repair ordinary ASCII
JSON files. No AI provider, cloud account, or screenshot egress is required.

Windows 11 developer preview. See the repository README for the locked installer,
local fixture demos, MCP session-token setup, and current live-validation limits.

This is a history-preserving downstream fork of OpenAdaptAI/openadapt-flow.
Its MIT copyright and package boundaries are retained. CreateRelay is unofficial
and unaffiliated with OpenAdapt, BandLab, Suno, or other automated applications.
